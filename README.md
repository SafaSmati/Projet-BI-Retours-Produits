# Projet BI — Analyse des Retours Produits

**Université de La Manouba — ESEN 2025/2026**
Élaboré par : Smati Safa & Marhag Mariem

## Description
Projet de Business Intelligence complet sur l'analyse des retours 
produits dans un réseau retail multi-magasins.

## Technologies utilisées
- Oracle SQL Developer — Data Warehouse
- Talend Open Studio — ETL
- Power BI — Tableaux de bord
- R Studio — Machine Learning

## Structure du projet
- 📁 Conception — Schéma en étoile
- 📁 ETL Talend — 4 jobs ETL
- 📁 Oracle SQL — Scripts de création
- 📁 Power BI — Dashboard interactif
- 📁 Machine Learning — Arbre de décision + Réseau de neurones
- 📁 Rapport — Rapport final PDF

## Résultats principaux
- 30 000 retours analysés sur 2020-2024
- 75,9M€ remboursés
- 191M€ de manque à gagner
- Catégorie Cat_11 et Magasin #17 identifiés comme prioritaires
- Réseau de neurones : 96,69% de précision

## Compétences mobilisées
Data Warehousing
ETL & Data Integration
SQL & Oracle Database
Data Visualization
Business Intelligence
Machine Learning
Analyse décisionnelle
